# Order Buyout Risk Prediction

ML-сервис для оценки вероятности невыкупа заказа с оплатой при получении.
Помогает интернет-магазину снизить расходы на обратную логистику: вместо жёсткой отмены заказов модель выявляет рискованные заказы для мягких продуктовых механик (предоплата или предупреждение о стоимости возврата).

## Ключевые решения
- **Без утечек данных:** написан кастомный трансформер `OrderFeatureEngineering` (`fit`/`transform`), который запоминает статистики категорий только на `train`.
- **Честная валидация:** `StratifiedGroupKFold` по `user_id` — заказы одного клиента не попадают одновременно в обучение и валидацию.
- **Бизнес-метрика:** подбор порога вероятности по матрице стоимости ошибок (логистика невыкупа vs упущенная маржа).
- **Микросервис:** REST API на `FastAPI` + `Pydantic` и упаковка в `Docker`.

## Стек
Python 3.11 • LightGBM • Scikit-learn • Pandas • FastAPI • Docker

## Структура проекта
- `src/data_gen.py` — генератор синтетических заказов с зависимыми признаками
- `src/features.py` — класс `OrderFeatureEngineering` (временные и агрегированные фичи)
- `src/train.py` — 5-фолдовая кросс-валидация, подбор порога и сохранение бандла
- `src/app.py` — FastAPI-сервис (`/health`, `/predict`)

## Результаты (5-fold StratifiedGroupKFold)
- Средний `ROC-AUC`: ~0.72 
- Оптимальный порог по деньгам: `0.40`

## Быстрый запуск

### Локально
```bash
pip install -r requirements.txt
python -m src.train
uvicorn src.app:app --reload
```
После запуска интерактивная документация (Swagger UI) доступна по адресу: `http://127.0.0.1:8000/docs`.

### Через Docker
```bash
docker build -t buyout-api .
docker run -p 8000:8000 buyout-api
```
